核心是**制作一个能加载模型并提供 HTTP API 服务的 Docker 镜像**。

### 自定义镜像

需要满足 ModelArts 规范，以下是几个关键点：
- **运行环境**：必须包含能够运行 Qwen3-VL 的软件栈，例如 PyTorch、`torch_npu`、`transformers` 库、`qwen_vl_utils` 等[](https://ai.gitcode.com/Ascend-SACT/Qwen3-VL-8B-Instruct)。你之前训练时用的 `mindspeed-mm` 基础镜像就可以作为很好的起点。
    
- **推理服务代码**：镜像里必须有一个 Python 脚本，它能做两件事：
    
    1. **加载模型**：启动时从指定路径（如容器内的 `/home/ma-user/model/`）加载你的模型权重文件。
        
    2. **启动 HTTP 服务**：监听 **`8080` 端口**[](https://support.huaweicloud.com/intl/zh-cn/inference-modelarts/inference2.0-modelarts-0003.html#1)，对外提供一个 API 接口（例如 `/predict` 或 `/generate`）来处理请求[](https://support.huaweicloud.com/intl/zh-cn/usermanual-standard-modelarts/modelarts_23_0219.html#1)。
        
- **启动脚本**：需要有一个 `run.sh` 或直接在 Dockerfile 中用 `CMD` 指令来启动你的推理服务[](https://support.huaweicloud.com/intl/zh-cn/usermanual-standard-modelarts/modelarts_23_0219.html#1)。
    
- **健康检查接口（推荐）**：实现一个 `/health` 或 `/ping` 接口，返回 200 状态码[](https://support.huaweicloud.com/intl/zh-cn/usermanual-standard-modelarts/modelarts_23_0219.html#1)[](https://support.huaweicloud.com/intl/zh-cn/inference-modelarts/inference2.0-modelarts-0003.html#1)。这能确保服务在滚动更新时不会中断业务[](https://support.huaweicloud.com/intl/zh-cn/usermanual-standard-modelarts/modelarts_23_0219.html#1)。

#### 一个简化的镜像内容示例
``` Dockerfile
# 1. 基于一个包含 PyTorch 和 NPU 环境的基础镜像
FROM swr.cn-south-1.myhuaweicloud.com/ascendhub/mindspeed-mm:26.0.0-910b-openeuler24.03-py3.11-aarch64

# 2. 设置工作目录
WORKDIR /home/ma-user

# 3. 安装推理需要的额外 Python 包
RUN pip install qwen_vl_utils transformers_stream_generator

# 4. 将你的推理服务脚本和启动脚本复制到镜像内
COPY inference_server.py /home/ma-user/
COPY run.sh /home/ma-user/

# 5. 设置启动脚本权限
RUN chmod +x /home/ma-user/run.sh

# 6. 声明容器监听的端口（ModelArts 要求 8080）
EXPOSE 8080

# 7. 指定容器启动时执行的命令
CMD ["sh", "/home/ma-user/run.sh"]
```

>[!INFO] 注意
> ModelArts 要求镜像内用户为 `ma-user` (uid 1000)[](https://doc.hcs.huawei.com/zh-cn/usermanual/modelarts/modelarts_23_0219.html)[](https://ai.gitcode.com/Ascend-SACT/Qwen3-VL-8B-Instruct)。如果使用非官方的基础镜像，需要在 Dockerfile 中创建这个用户[](https://ai.gitcode.com/Ascend-SACT/Qwen3-VL-8B-Instruct)。镜像大小不要超过 **50GB**[](https://doc.hcs.huawei.com/zh-cn/usermanual/modelarts/modelarts_23_0219.html)。
