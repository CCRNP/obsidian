
> [!waring] 告警信息
> Warning: /dev/euleros/root does not exist
> Warning: /dev/euleros/swap does not exist
> Warning: /dev/mapper/euleros-root does not exist

这三个警告明确指向 **LVM（逻辑卷管理）** 配置问题。系统期望根文件系统和交换分区位于名为 `euleros` 的卷组（VG）中，逻辑卷名分别为 `root` 和 `swap`。但在启动时，initramfs 无法找到这些逻辑卷。

### 为什么镜像在裸金属上会找不到 LVM 逻辑卷？

#### 1. LVM 元数据未正确识别或卷组未激活

#### 2. 缺少裸金属存储驱动，导致底层物理卷（PV）不可见

#### 3. 内核引导参数 `root=` 指定不正确



## 解决

### 准备工作：安装 libguestfs-tools

这个工具包提供了强大的离线修改能力，在你当前用于修复的宿主机上安装它。

```
# 在 CentOS / RHEL / 麒麟，EulerOS 等系统上：
sudo yum install -y libguestfs-tools

# 在 Debian / Ubuntu 等系统上：
sudo apt-get update && sudo apt-get install -y libguestfs-tools
```

### 方案一：使用 guestfish (推荐)
```
启动 guestfish 会话
sudo guestfish --rw -a /path/to/your/euleros-v2sp10-x86_64_uefi.qcow2

# 1. 启动虚拟系统，这是必须的第一步
><fs> run

# 2. 查看镜像内的所有文件系统，找到根分区 (例如：/dev/euleros/root)
><fs> list-filesystems

# 3. 挂载根文件系统 (请根据上一步的输出替换下面的路径)
><fs> mount /dev/euleros/root /

# 4. 为了方便，将 /dev, /proc, /sys 等目录 bind 到 chroot 环境
#    这一步对执行 dracut 等命令至关重要
><fs> mount /dev /dev
><fs> mount /proc /proc
><fs> mount /sys /sys

# 5. 现在可以开始修复了，进入 chroot 环境并执行命令。
#    使用 sh 直接运行多条命令。
><fs> sh "chroot / dracut --force --add-drivers 'nvme megaraid_sas mpt3sas ahci'"

# 6. 检查并修正 GRUB 配置 (以 UEFI 模式为例)
><fs> sh "chroot / sed -i 's/root=\/dev\/mapper\/euleros-root/root=UUID=$(lsblk -o UUID /dev/euleros/root | tail -n1)/' /boot/efi/EFI/euleros/grub.cfg"
#   (上面的命令是示例，更稳妥的手动编辑方式请看下文)

# 7. (可选) 确认 /etc/fstab 也使用了正确的 UUID
><fs> sh "chroot / blkid /dev/euleros/root"  # 获取 UUID
><fs> edit /etc/fstab
#   将 /etc/fstab 中的 /dev/mapper/euleros-root 行也替换为 UUID=你的UUID
#   注意：在 guestfish 中，edit 命令会调用主机上的默认编辑器

# 8. 全部操作完成后，退出 guestfish
><fs> exit
```


6. 修改 GRUB 配置：

首先获取根文件系统的 UUID：
> <fs\> sh "blkid -s UUID -o value /dev/euleros/root"
> 998cc387-af45-48e4-8f85-b02a092955f5

编辑 GRUB 配置文件：
`<fs> edit /boot/efi/EFI/euleros/grub.cfg`

找到 `linux` 开头的行，将 `root=/dev/mapper/euleros-root` 或 `root=/dev/euleros/root` 改为 `root=UUID=998cc387-af45-48e4-8f85-b02a092955f5。保存退出。

 获取交换分区的 UUID:
`><fs> sh "blkid -s UUID -o value /dev/euleros/swap"`
获取如下：
`fdc734f2-b498-41c2-8896-83c6d421d562`

编辑 `/etc/fstab`：
`><fs> edit /etc/fstab`


```
原内容：
/dev/mapper/euleros-root / ext4 defaults,iversion 1 1
UUID=46f369a7-65c2-4786-933c-3681b4523056 /boot ext4 defaults,iversion 1 2
UUID=22D1-EE6C          /boot/efi               vfat    umask=0077,shortname=winnt 0 2
/dev/mapper/euleros-swap none                    swap    defaults        0 0

修改后（将根分区和 swap 都改用 UUID）：
UUID=998cc387-af45-48e4-8f85-b02a092955f5 / ext4 defaults,iversion 1 1
UUID=46f369a7-65c2-4786-933c-3681b4523056 /boot ext4 defaults,iversion 1 2
UUID=22D1-EE6C          /boot/efi               vfat    umask=0077,shortname=winnt 0 2
UUID=<你查到的swap UUID> none swap defaults 0 0
```
