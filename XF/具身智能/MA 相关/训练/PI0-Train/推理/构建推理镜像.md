## 通过 cbh 虚拟机制作

### 在 `/var/lib/docker` 下创建工作目录
```bash
mkdir -p /var/lib/docker/workspace/pi0-inference
cd /var/lib/docker/workspace/pi0-inference
```

### 准备文件

将 `Dockerfile` 和 `model` 文件夹（包含 `customize_service.py`、`config.json`、`model.safetensors` 等）放入此目录

### 构建镜像

```bash
docker build -t pi0-inference:latest .
```

## 注意事项

清理旧镜像/容器：如果 /var/lib/docker 中已有大量无用镜像，可先执行 docker system prune -f 释放空间。

构建上下文：model 文件夹如果很大（含 14GB 权重），构建时 COPY 会占用额外空间，但仍在 64G 限额内。

验证可用空间：构建前执行 df -h /var/lib/docker 确认剩余空间是否 > 50G（目前是 64G，没问题）。
