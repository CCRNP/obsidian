在数管平台上落地模型评测，核心是写一个“**任务型脚本**”——它不需要重复实现训练平台已有的评测能力，而是作为**调度器和连接器**，去调用训练平台部署好的推理服务，用测试集跑推理，算指标，然后把结果写回数管平台。

下面从**设计思路、脚本结构、核心代码模板、与数管平台对接**四个层面来说。


### 一、先想清楚：脚本的边界在哪里

在动笔之前，需要明确哪些是脚本该做的，哪些不该做：

| 职责      | 是否属于脚本       | 说明                    |
| ------- | ------------ | --------------------- |
| 加载测试集   | ✅ 是          | 从数管平台指定的路径读取评测数据      |
| 调用推理服务  | ✅ 是          | 把测试集输入发到训练平台的在线服务API  |
| 计算评测指标  | ✅ 是          | 准确率、F1、BLEU等，根据任务类型选择 |
| 生成评测报告  | ✅ 是          | 输出结构化结果（JSON/CSV）     |
| 写回数管平台  | ✅ 是          | 把评测结果回写至指定数据库或API     |
| 模型推理计算  | ❌ 否          | 由训练平台的推理服务完成          |
| 模型训练/微调 | ❌ 否          | 由训练平台完成               |
| 评测任务调度  | ❌ 是（由数管平台承担） | 数管平台触发脚本执行            |

**一句话**：脚本是数管平台和训练平台之间的“评测执行器”，它负责**驱动评测流程**，而不是**实现评测算法本身**。


### 二、脚本的完整结构（四段式）

一个可运行的评测脚本，按执行顺序分为四个阶段：

```
┌─────────────────────────────────────────────────┐
│  阶段一：初始化                                   │
│  - 解析参数（模型服务地址、测试集路径、输出路径）  │
│  - 加载测试数据集                                 │
│  - 初始化评测指标计算器                            │
├─────────────────────────────────────────────────┤
│  阶段二：批量推理                                 │
│  - 遍历测试集，逐条（或批量）调用模型推理API       │
│  - 收集模型输出                                   │
│  - 处理超时、重试、异常                        │
├─────────────────────────────────────────────────┤
│  阶段三：指标计算                                 │
│  - 将模型输出与标准答案比对                       │
│  - 计算准确率/精确率/召回率/F1/BLEU等指标         │
├─────────────────────────────────────────────────┤
│  阶段四：结果输出                                 │
│  - 生成结构化评测报告（JSON）                     │
│  - 写入指定输出路径                               │
│  - 回写数管平台                                   │
└─────────────────────────────────────────────────┘
```


### 三、核心代码模板（可直接作为起点）

以下是一个**通用评测脚本**的Python模板，覆盖了上述四个阶段：

```python
#!/usr/bin/env python3
"""
模型评测脚本 - 数管平台专用
功能：调用训练平台推理服务，对指定测试集进行评测，输出评测报告
"""

import argparse
import json
import time
import requests
import pandas as pd
from typing import List, Dict, Any
from sklearn.metrics import accuracy_score, precision_recall_fscore_support


class ModelEvaluator:
    """模型评测器：驱动整个评测流程"""

    def __init__(self, config: Dict[str, Any]):
        """
        初始化评测器

        Args:
            config: 评测配置字典，包含：
                - service_url: 推理服务API地址
                - api_key: 服务认证密钥（如有）
                - testset_path: 测试集文件路径（JSONL/CSV格式）
                - output_path: 评测报告输出路径
                - task_type: 任务类型（classification/generation/qa等）
                - metrics: 需要计算的指标列表
                - batch_size: 批量推理的批大小
                - max_retries: API调用最大重试次数
        """
        self.config = config
        self.service_url = config.get("service_url")
        self.api_key = config.get("api_key", "")
        self.testset_path = config.get("testset_path")
        self.output_path = config.get("output_path", "./eval_report.json")
        self.task_type = config.get("task_type", "classification")
        self.metrics = config.get("metrics", ["accuracy", "f1"])
        self.batch_size = config.get("batch_size", 1)
        self.max_retries = config.get("max_retries", 3)

        self.testset: List[Dict] = []
        self.predictions: List[Any] = []
        self.ground_truths: List[Any] = []
        self.raw_outputs: List[Dict] = []

    # ==================== 阶段一：初始化 ====================

    def load_testset(self):
        """加载测试数据集（支持JSONL和CSV格式）"""
        print(f"[INFO] 加载测试集: {self.testset_path}")

        if self.testset_path.endswith(".jsonl"):
            with open(self.testset_path, "r", encoding="utf-8") as f:
                for line in f:
                    if line.strip():
                        self.testset.append(json.loads(line))
        elif self.testset_path.endswith(".csv"):
            df = pd.read_csv(self.testset_path)
            self.testset = df.to_dict(orient="records")
        else:
            raise ValueError(f"不支持的测试集格式: {self.testset_path}")

        print(f"[INFO] 测试集加载完成，共 {len(self.testset)} 条样本")

        # 提取标准答案（根据数管平台的字段规范）
        self.ground_truths = [
            item.get("label") or item.get("answer") or item.get("ground_truth")
            for item in self.testset
        ]

    # ==================== 阶段二：批量推理 ====================

    def call_inference_api(self, input_text: str) -> Dict:
        """
        调用训练平台的推理服务API

        这里以OpenAI兼容接口为例，实际需根据训练平台的
        API规范调整请求格式和响应解析逻辑。
        """
        headers = {"Content-Type": "application/json"}
        if self.api_key:
            headers["Authorization"] = f"Bearer {self.api_key}"

        payload = {
            "messages": [{"role": "user", "content": input_text}],
            "temperature": 0.1,  # 评测时用低温度，保证结果稳定
            "max_tokens": 512,
        }

        for attempt in range(self.max_retries):
            try:
                resp = requests.post(
                    self.service_url,
                    json=payload,
                    headers=headers,
                    timeout=60,
                )
                resp.raise_for_status()
                return resp.json()
            except requests.exceptions.RequestException as e:
                print(f"[WARN] API调用失败 (尝试 {attempt+1}/{self.max_retries}): {e}")
                if attempt < self.max_retries - 1:
                    time.sleep(2 ** attempt)  # 指数退避
                else:
                    raise

    def run_batch_inference(self):
        """批量推理：遍历测试集，收集模型输出"""
        print(f"[INFO] 开始批量推理，共 {len(self.testset)} 条样本")

        for i, item in enumerate(self.testset):
            # 提取输入文本（根据数管平台的字段规范）
            input_text = (
                item.get("input")
                or item.get("question")
                or item.get("prompt")
                or item.get("text")
            )

            try:
                result = self.call_inference_api(input_text)
                prediction = self._extract_prediction(result)
                self.predictions.append(prediction)
                self.raw_outputs.append(result)
            except Exception as e:
                print(f"[ERROR] 第 {i+1} 条样本推理失败: {e}")
                self.predictions.append(None)
                self.raw_outputs.append({"error": str(e)})

            if (i + 1) % 10 == 0:
                print(f"[INFO] 已完成 {i+1}/{len(self.testset)} 条")

        print(f"[INFO] 批量推理完成")

    def _extract_prediction(self, api_result: Dict) -> Any:
        """从API返回结果中提取预测值（根据训练平台响应格式调整）"""
        # 分类任务：取标签
        if self.task_type == "classification":
            return (
                api_result.get("label")
                or api_result.get("prediction")
                or api_result.get("result")
            )
        # 生成任务：取文本
        else:
            choices = api_result.get("choices", [])
            if choices:
                return choices[0].get("message", {}).get("content", "")
            return api_result.get("output", "")

    # ==================== 阶段三：指标计算 ====================

    def compute_metrics(self) -> Dict:
        """根据任务类型计算评测指标"""
        results = {}

        if self.task_type == "classification":
            # 过滤掉预测失败的样本
            valid_pairs = [
                (gt, pred)
                for gt, pred in zip(self.ground_truths, self.predictions)
                if pred is not None
            ]
            if not valid_pairs:
                return {"error": "无有效预测结果"}

            gts, preds = zip(*valid_pairs)

            if "accuracy" in self.metrics:
                results["accuracy"] = round(accuracy_score(gts, preds), 4)

            if "f1" in self.metrics or "precision" in self.metrics:
                precision, recall, f1, _ = precision_recall_fscore_support(
                    gts, preds, average="weighted", zero_division=0
                )
                results["precision"] = round(precision, 4)
                results["recall"] = round(recall, 4)
                results["f1"] = round(f1, 4)

        elif self.task_type == "generation":
            # 生成任务：可接入BLEU/ROUGE/困惑度等
            # 这里预留接口，实际需引入对应计算库
            results["num_samples"] = len(self.predictions)
            results["num_valid"] = sum(1 for p in self.predictions if p)

            # 示例：简单计算平均响应长度
            valid_preds = [p for p in self.predictions if p]
            if valid_preds:
                results["avg_response_length"] = round(
                    sum(len(p) for p in valid_preds) / len(valid_preds), 2
                )

        results["total_samples"] = len(self.testset)
        results["failed_samples"] = sum(1 for p in self.predictions if p is None)

        return results

    # ==================== 阶段四：结果输出 ====================

    def generate_report(self) -> Dict:
        """生成结构化评测报告"""
        metrics = self.compute_metrics()

        report = {
            "eval_time": time.strftime("%Y-%m-%d %H:%M:%S"),
            "service_url": self.service_url,
            "testset_path": self.testset_path,
            "task_type": self.task_type,
            "metrics": metrics,
            "details": [
                {
                    "index": i,
                    "ground_truth": self.ground_truths[i],
                    "prediction": self.predictions[i],
                }
                for i in range(len(self.testset))
            ],
        }

        return report

    def save_report(self, report: Dict):
        """保存评测报告到指定路径"""
        with open(self.output_path, "w", encoding="utf-8") as f:
            json.dump(report, f, ensure_ascii=False, indent=2)
        print(f"[INFO] 评测报告已保存至: {self.output_path}")

    # ==================== 主流程 ====================

    def run(self) -> Dict:
        """执行完整评测流程"""
        self.load_testset()
        self.run_batch_inference()
        report = self.generate_report()
        self.save_report(report)
        return report


# ==================== 命令行入口 ====================

def parse_args():
    parser = argparse.ArgumentParser(description="模型评测脚本")
    parser.add_argument("--service-url", required=True, help="推理服务API地址")
    parser.add_argument("--api-key", default="", help="服务认证密钥")
    parser.add_argument("--testset", required=True, help="测试集文件路径")
    parser.add_argument("--output", default="./eval_report.json", help="评测报告输出路径")
    parser.add_argument("--task-type", default="classification",
                        choices=["classification", "generation", "qa"],
                        help="任务类型")
    parser.add_argument("--metrics", default="accuracy,f1", help="需要计算的指标，逗号分隔")
    parser.add_argument("--batch-size", type=int, default=1, help="批量推理批大小")
    return parser.parse_args()


if __name__ == "__main__":
    args = parse_args()

    config = {
        "service_url": args.service_url,
        "api_key": args.api_key,
        "testset_path": args.testset,
        "output_path": args.output,
        "task_type": args.task_type,
        "metrics": args.metrics.split(","),
        "batch_size": args.batch_size,
    }

    evaluator = ModelEvaluator(config)
    report = evaluator.run()

    print("\n===== 评测结果摘要 =====")
    print(json.dumps(report["metrics"], ensure_ascii=False, indent=2))
```


### 四、与数管平台的对接方式

脚本写好后，需要和数管平台打通。推荐**“配置驱动 + API回写”**的模式：

**1. 输入侧：数管平台传给脚本的参数**

数管平台在触发评测任务时，通过命令行参数或环境变量传入以下信息：

| 参数 | 来源 | 示例 |
|---|---|---|
| `--service-url` | 训练平台在线服务的API地址 | `http://10.3.28.18:7081/v1/chat/completions` |
| `--testset` | 数管平台指定的测试集路径 | `/data/eval/testset.jsonl` |
| `--output` | 评测报告输出路径 | `/data/eval/reports/report_001.json` |
| `--task-type` | 评测任务类型 | `classification` |
| `--metrics` | 需要计算的指标 | `accuracy,f1,precision` |

**2. 输出侧：脚本回写数管平台**

脚本生成评测报告后，通过数管平台提供的API将结果回写：

```python
def writeback_to_platform(report: Dict, platform_api: str):
    """
    将评测结果回写至数管平台

    Args:
        report: 评测报告字典
        platform_api: 数管平台的结果接收API地址
    """
    payload = {
        "task_id": report.get("task_id"),  # 数管平台传入的任务ID
        "status": "completed",
        "metrics": report["metrics"],
        "report_path": report.get("output_path"),
    }

    try:
        resp = requests.post(platform_api, json=payload, timeout=30)
        resp.raise_for_status()
        print(f"[INFO] 评测结果已回写至数管平台")
    except Exception as e:
        print(f"[ERROR] 回写失败: {e}")
```

**3. 数管平台侧的调度逻辑**

数管平台负责：
- 创建评测任务时，生成唯一 `task_id`
- 准备测试集文件（从数管平台的数据管理模块导出）
- 调用评测脚本，传入参数
- 接收脚本回写的评测结果，存入数据库并展示


### 五、几个关键设计决策

**1. 测试集格式规范**

建议数管平台统一使用 **JSONL格式**，每条样本包含 `input` 和 `ground_truth` 两个核心字段：

```jsonl
{"input": "今天天气怎么样？", "ground_truth": "今天晴转多云，气温25度"}
{"input": "帮我订一张去北京的机票", "ground_truth": "好的，请提供出发日期和航班偏好"}
```

字段名可根据实际业务调整，但需要在脚本的 `_extract_prediction` 和 `load_testset` 中保持对应。

**2. 评测指标与任务类型的对应**

| 任务类型 | 推荐指标 | 计算方式 |
|---|---|---|
| 分类任务 | 准确率、精确率、召回率、F1 | 调用 `sklearn.metrics` |
| 生成任务 | BLEU、ROUGE、困惑度 | 调用 `nltk` 或 `sacrebleu` |
| 问答任务 | 精确匹配、F1、ROUGE-L | 自定义或 `evaluate` 库 |
| 大模型开放问答 | LLM-as-judge 打分 | 调用裁判模型API |

**3. 异常处理**

评测脚本必须处理以下异常，否则数管平台会收到“任务卡死”的状态：
- **API调用失败**：重试 + 记录失败样本，不阻塞整体流程
- **测试集格式错误**：提前校验，给出明确的错误信息
- **指标计算异常**：捕获并返回部分结果，而非整个脚本崩溃

**4. 性能考量**

如果测试集很大（几千条以上），逐条调用API会非常慢。建议：
- **支持批推理**：如果训练平台的推理服务支持batch请求，一次性发多条
- **并发调用**：使用 `asyncio` 或 `ThreadPoolExecutor` 并发调用API
- **进度记录**：支持断点续跑，避免因中断导致全部重来


### 六、给数管平台开发同事的落地建议

如果要把这个脚本交给数管平台的开发团队去实现，建议这样沟通：

> 评测脚本的核心职责是：**接收数管平台传入的测试集和模型服务地址，批量调用推理服务，计算指标，返回结构化报告**。
>
> 脚本需要三个接口：
> 1. **输入接口**：命令行参数或环境变量，接收 `service_url`、`testset_path`、`task_type`、`metrics` 四个核心参数
> 2. **输出接口**：生成JSON格式的评测报告，包含指标汇总和逐条详情
> 3. **回写接口**：调用数管平台的结果接收API，把报告写回去
>
> 脚本不需要实现推理计算，那是训练平台的职责；也不需要实现任务调度，那是数管平台的职责。它只做**评测执行**这一件事。
