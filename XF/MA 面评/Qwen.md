###  总结

| 组成部分     | 具体内容                                             |
| -------- | ------------------------------------------------ |
| **模型结构** | `Qwen3-VL-8B-Instruct` 的 `config.json`（定义神经网络架构） |
| **训练起点** | **随机初始化的权重**（没有加载预训练权重）                          |

| **训练硬件** | 昇腾 910B NPU（2卡或4卡）                               |
