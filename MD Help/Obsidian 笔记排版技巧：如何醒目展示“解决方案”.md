# Obsidian 笔记排版技巧：如何醒目展示“解决方案”

## 一、核心方案：Obsidian Callout（标注/高亮块）
**特点**：带颜色背景、带图标、视觉冲击力最强。最推荐用于排障笔记的“解决方案”。
*支持类型*：`[!success]`（绿色成功）、`[!info]`（蓝色信息）、`[!warning]`（黄色警告）、`[!danger]`（红色危险）。

**普通 Callout 源码（直接复制）：**
```markdown
> [!success] 🛠️ 解决方案
> 具体操作详见：[[A100 - GPU驱动升级失败修复步骤总结]]
```

**折叠 Callout 源码（点击展开，完美解决内容太长的问题）：**
```markdown
> [!success]- 🛠️ 解决方案（点击展开）
> 具体操作详见：[[A100 - GPU驱动升级失败修复步骤总结]]
> 
> *(如果有需要，以后也可以把核心命令直接写在下面，替代掉纯链接)*
```

## 二、传统方案：分割线 + 独立标题
**特点**：不依赖 Callout 插件，通用性极强（标准 Markdown 语法）。
**源码：**
```markdown
---
### 🛠️ 解决方案
**具体操作详见：** [[A100 - GPU驱动升级失败修复步骤总结]]
```

## 三、紧凑方案：引用块 + Emoji
**特点**：不占太多空间，但左侧的竖线和 Emoji 依然能起到明显的区分作用。
**源码：**
```markdown
> **✅ 解决方案：** 具体操作详见 [[A100 - GPU驱动升级失败修复步骤总结]]
```

## 四、Obsidian 专属双链技巧（配合你的同级目录）
既然你使用的是同级目录的 `[[ ]]` 双链，强烈建议你在链接后加上 `|别名`，这样阅读时体验更好，不会显示冗长的文件名。

**源码：**
```markdown
> [!success] 🛠️ 解决方案
> 点击查看具体步骤：[[A100 - GPU驱动升级失败修复步骤总结|👉 驱动修复指南]]
```
*效果：鼠标悬浮可以预览，点击直接跳转，且显示的文本是你自定义的别名。*

## 📝 附：排障笔记标准模板（可直接复制使用）
结合你截图里非常好的逻辑（问题现象 -> 原因分析 -> 解决方案），推荐你以后排障都套用这个模板：

```markdown
#### 问题2 升级完后，nvidia-smi 无法识别设备

**📌 问题现象**
从470升级到570失败，nvidia-smi 无法识别设备。

**🔍 原因分析**
- **470驱动（旧时代）**：默认不使用 GSP 来管理 GPU，所以没有 GSP 固件也能工作。
- **570驱动（新时代）**：从535版本开始默认启用 GSP，启动时会强制加载 `gsp_tu10x.bin`。HCE 2.0 系统缺失此文件，内核报 `error -2`，导致无法识别。

**🛠️ 解决方案**
> [!success] 修复操作
> 具体操作详见：[[A100 - GPU驱动升级失败修复步骤总结]]
> 
> **核心步骤摘要**（建议补充）：
> 1. 提取对应版本的 `gsp_tu10x.bin` 固件。
> 2. 放入 `/lib/firmware/nvidia/570.xx.xx/` 目录下。
> 3. 重启驱动或执行 `nvidia-smi` 验证。
```

*(提示：复制上述代码块中的内容到 Obsidian，即可直接渲染出带颜色的折叠高亮块。)*
